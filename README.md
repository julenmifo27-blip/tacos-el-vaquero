# Tacos El Vaquero

Crónica web breve sobre Tacos El Vaquero, la taquería 24 horas de la glorieta de Santa Fe que la alcaldía mandó a un segundo piso. Está dividida en la mañana, la tarde de los godínez y la noche de los borrachitos, cada una con su carrusel de fotos.

Fotos: Analu, Julen y Tocho.

## Correrlo en local

```bash
npm install
npm run dev
```

## Publicar

```bash
npm run build
```

La carpeta `dist/` se publica en la rama `gh-pages` (GitHub Pages).

## Hecho con

Vite, React, TypeScript, Tailwind CSS v4, Framer Motion y el componente `TiltedGridHero` de 21st.dev. Fuentes: Saira Stencil One, Yellowtail y Archivo.
